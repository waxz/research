Survey analysis · robot control paradigms · Oct 2026

Model, reward, or reference?

Every robot controller has to get its knowledge of what to do from somewhere. Model-based control gets it from equations of motion and a cost function. Reinforcement learning gets it from a reward and a large amount of trial and error. Supervised and reference-based learning get it from examples of the behavior. This page compares the three families using the main survey and overview papers, explains why robot control is hard, weighs reference-guided RL against free exploration, and maps real tasks to the method that fits them.

Model-based control“I know the physics; optimize.”
PID, LQR, trajectory optimization, MPC, whole-body QP control. MB
Self-exploration RL“I know what good looks like; search.”
Policy learned from a task reward alone, usually in simulation with domain randomization. RL
Reference / supervised learning“I can show you; copy and refine.”
Behavior cloning, DAgger, teacher–student distillation, inverse RL, and RL that tracks reference motions. REF

“Supervised RL” isn't a standard term. Here it means every method where the learning signal comes from demonstrations or reference trajectories instead of, or on top of, a task reward. Section 3 splits this into pure imitation and reference-based RL.

Part 1Why robot control is hard

Start with the equation every legged or manipulating robot obeys. For a floating-base robot with generalized coordinates \(q\) (6 base DoF plus \(n\) joints; for a Unitree G1, \(n=29\)) [Featherstone 2008; Wensing 2024]:

Floating-base rigid-body dynamics with contact \[ M(q)\,\ddot q + C(q,\dot q)\,\dot q + g(q) \;=\; S^\top \tau \;+\; \sum_{c\,\in\,\mathcal C(t)} J_c(q)^\top \lambda_c \] \[ 0 \le \lambda_{c,n} \;\perp\; \phi_c(q) \ge 0, \qquad \|\lambda_{c,t}\| \le \mu\,\lambda_{c,n} \]

Each term is a separate source of difficulty. \(M, C, g\) are nonlinear in \(q\). The selection matrix \(S\) has no rows for the floating base, so the robot is underactuated: it can only move its torso by pushing on the world. The contact set \(\mathcal C(t)\) switches discretely, and the complementarity condition (\(\perp\): the force is nonzero only when the gap \(\phi\) is zero) makes the dynamics hybrid and non-smooth. The friction cone limits which forces are available at all.

Curse of dimensionalityDynamic programming on a grid of a 70-D state is impossible, so every practical method approximates: local linearization (LQR, MPC), templates (LIPM, SRBD), or function approximation (neural policies).Hits: MB (needs reduced models) · RL (sample cost)
Combinatorial contact schedulesWhich foot or hand touches what, and when, is a discrete choice. Mixed-integer or contact-implicit optimization is expensive, so most MPC fixes the gait schedule in advance [Posa 2014; Di Carlo 2018].Hits: MB hardest · RL learns it implicitly
Non-smooth gradientsContact makes the dynamics stiff or discontinuous. Gradient-based optimizers and differentiable simulators can get biased or exploding gradients [Suh 2022].Hits: MB, differentiable-sim RL
Model mismatchReal friction, motor dynamics, cable stretch and compliance are not in \(M, C, g\). This drives both MPC robustness work and RL domain randomization [Tobin 2017; Peng 2018].Hits: all
Specifying the goalWriting a cost or reward that yields natural, safe and useful motion is hard. Policies exploit loopholes (reward hacking), which is a main reason references and demonstrations are used.Hits: RL hardest · REF avoids it
Safety, data and wearReal-world trial and error damages hardware and takes time. Dulac-Arnold et al. list nine such challenges for real-world RL [Dulac-Arnold 2021].Hits: RL on hardware · REF data cost

The usual decision rule comes from these: model-based control wins when the difficulty can be removed with a good reduced model. RL wins when the difficulty is in contact, uncertainty or dimension but the goal is easy to score. Reference learning wins when the goal itself is the hard part to write down.

Part 2Three paradigms, side by side

MB Model-based optimal control

Write down a model \(f\) and a cost \(\ell\), then solve a finite-horizon optimal control problem online, apply the first input, and repeat (receding horizon):

Model predictive control \[ \min_{u_{0:N-1}} \; \sum_{k=0}^{N-1} \ell(x_k, u_k) + \ell_f(x_N) \quad \text{s.t.}\quad x_{k+1} = f(x_k,u_k),\;\; h(x_k,u_k) \le 0,\;\; x_0 = \hat x(t) \]

For legged robots the model is usually reduced (single rigid body, centroidal dynamics) and a whole-body QP maps the MPC plan to joint torques at around 1 kHz [Kim 2019; Kuindersma 2016]. MPC handles constraints explicitly and its behavior is interpretable and tunable, but solving the full contact-rich problem online is still intractable [Wensing 2024].

RL Self-exploration reinforcement learning

Specify only a reward and let the policy discover behavior. For sim-to-real robustness, optimize across a distribution of randomized simulators \(\xi\):

Domain-randomized RL objective \[ \max_\theta \; \mathbb E_{\xi \sim p(\xi)}\, \mathbb E_{\tau \sim \pi_\theta,\,\xi}\Big[\sum_t \gamma^t r(s_t,a_t)\Big] \]

Song et al.'s drone-racing study states the advantage precisely: RL is not better at optimizing, it optimizes a better objective. It can score the task directly (lap time, staying upright) instead of tracking a planned trajectory, and it can be made robust by randomization [Song 2023]. The cost is sample complexity: millions to billions of simulated steps, an accurate-enough simulator, and reward design.

REF Supervised and reference-based learning

Learn from examples. The simplest form is behavior cloning, regression from observations to expert actions:

Behavior cloning and its compounding error \[ \min_\theta \; \mathbb E_{(o,a)\sim\mathcal D}\big[-\log \pi_\theta(a\mid o)\big], \qquad J(\hat\pi) \le J(\pi^*) + T^2\epsilon \;\;\text{(BC)} \quad\text{vs.}\quad J(\pi^*) + uT\epsilon \;\;\text{(DAgger)} \]

Here \(\epsilon\) is the per-step imitation error and \(T\) the horizon. Because the cloned policy visits states the expert never did, errors compound quadratically. DAgger fixes this by querying the expert on the learner's own states, bringing the bound to linear [Ross & Bagnell 2010; Ross 2011]. Teacher–student distillation in legged and humanoid robotics is DAgger with an RL-trained, privileged teacher [Lee 2020]. Inverse RL and GAIL recover a reward from demonstrations instead [Ng & Russell 2000; Ho & Ermon 2016].

The surveys agree that hybrids are winning. Reiter et al. classify MPC–RL combinations and argue the two differ mainly in how they treat the model, which makes them complementary [Reiter 2026]. Ha et al. describe learning-based legged locomotion as complementing, not replacing, model-based control [Ha 2025]. Hewing et al. review learning-based MPC [Hewing 2020]. Examples: RL tracking MPC/TO plans (DTC, [Jenelten 2024]), residual RL on top of classical controllers [Johannink 2019], and learned world models used for planning or gradients (TD-MPC, SuperMimic).

Part 3Reference-based RL vs self-exploration RL

Both run RL, usually PPO in simulation. They differ in the reward. Self-exploration RL scores the task and lets the policy discover how. Reference-based RL scores closeness to a given motion and lets the policy discover only how to make that motion physically feasible.

Self-exploration: task reward + shaping + regularizers (typical locomotion) \[ r_t = \underbrace{w_v\, e^{-\|v^{\text{cmd}}_{xy} - v_{xy}\|^2/\sigma^2}}_{\text{task}} \;-\; \underbrace{w_\tau \|\tau\|^2 - w_a\|a_t-a_{t-1}\|^2 - w_o \|\omega_{xy}\|^2}_{\text{regularizers}} \;+\; \underbrace{w_f\, r_{\text{feet-air-time}} + \dots}_{\text{hand-tuned shaping}} \]
Reference-based: imitation reward (DeepMimic family), optionally plus a task term \[ r_t = w^I\, \underbrace{\sum_k w_k \exp\!\big(-\|x^{\text{ref}}_{k,t} - x_{k,t}\|^2/\sigma_k^2\big)}_{\text{track reference poses, velocities, end-effectors}} \;+\; w^G\, r^{\text{goal}}_t \]

Reference-based RL also changes exploration. Episodes start at random points of the reference (reference-state initialization) and end early when the robot drifts away, so the policy never wastes samples on states unrelated to the motion [Peng 2018]. A middle ground replaces exact tracking with a learned style prior. AMP trains a discriminator \(D\) on motion clips and rewards the policy for looking like the data, \(r^{\text{style}} = \max[0,\,1 - 0.25(D(s,s')-1)^2]\), without tracking any one clip [Peng 2021; Escontrela 2022].

The practical synthesis. Use references to set what the motion looks like and rewards to set what the motion achieves. Current humanoid stacks train a general reference tracker first (BeyondMimic, SONIC, SuperMimic), then put a task layer on top, trained by distillation, diffusion guidance or task RL through the same model. SuperMimic's small study found task RL through the world model beat distillation for velocity commands on 650 of 672 test commands.

Part 4Which method for which real-world task

Two questions cover most of the decision. Can you model or simulate the system faithfully? Is the desired behavior easier to score or to show? The map below places common tasks on those two axes.

Decision flow

flowchart TD
  A[New control task] --> B{Need formal safety or constraint guarantees?}
  B -- yes --> MB1[Model-based control: MPC or WBC, optionally with learned residuals]
  B -- no --> C{Can you write a tractable model and solve it in real time?}
  C -- yes --> MB2[Model-based control first; add RL only for the hard parts]
  C -- no --> D{Can you simulate it faithfully?}
  D -- no --> E[Imitation learning from teleop demos: diffusion policy or VLA; fine-tune with real RL if needed]
  D -- yes --> F{Is the behavior easier to score than to show?}
  F -- score --> G[Self-exploration RL with domain randomization; distill to a deployable student]
  F -- show --> H[Reference-based RL: tracking reward or AMP style prior; add a task layer on top]
  G --> I{Motion looks unnatural or reward-hacks?}
  I -- yes --> H
